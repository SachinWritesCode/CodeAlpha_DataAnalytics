# CodeAlpha Internship — Task 2 (EDA) and Task 3 (Data Visualization)

This beginner-friendly project analyzes an illustrative retail sales dataset. The CSV is included, so no separate database is needed.

## Tasks covered
- Task 2: inspect data types, summary statistics, missing values, trends, category/region patterns, and data-quality issues.
- Task 3: create monthly sales, category sales, and product quantity charts.

## Setup
Install Python 3.10+ and run:
```bash
pip install pandas matplotlib
python analysis.py
```
The script saves charts in the `charts` folder and prints key findings.

## Dataset note
`retail_sales.csv` is an illustrative, locally prepared sample dataset for demonstrating analysis workflow; it is not real company data. For submission, explain that limitation honestly.
